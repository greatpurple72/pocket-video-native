# 愿景与产品支柱(North Star)

> 本文件描述**不轻易改变**的顶层方向。改动需新增 ADR 说明理由。

## 一句话愿景
做一款**让你亲手踢实时比赛**的**全球向、街机/休闲调性的足球 SLG**(卡通画风,见 ADR-0004)——把体育竞技的操作快感,装进 SLG 的长线养成与社交对抗里。

## 三大产品支柱
1. **手感为王(Feel First)**:实时可控的标准 11v11 比赛,操作手感是第一壁垒。手感不过关,一切免谈。
2. **俱乐部帝国(Meta Depth)**:球员抽卡 + 俱乐部养成 + 联盟/联赛 PvP + 跨服 + 活动运营,构成长线无底洞。
3. **比赛即战斗(The Hook)**:把"亲手踢的比赛"做成 SLG 的战斗结算层——这是所有头部 SLG 都没有的差异化。

## 目标用户
- 全球市场;足球爱好者 + SLG/4X 玩家的交集与外延。
- 通过足球爽点小游戏(点球/任意球/过人)做 hybrid-casual 买量,漏斗导入中核 SLG。

## 不做什么(防范围蔓延)
- 不在玩法验证前堆砌后端/运营系统。
- 不自制 3D 美术/动画(起步用 Fab/Mixamo/商城现成资源,先占位后替换)。
- 不追求第一年 1:1 复刻 Konami/Century Games 的完成度;以**可玩的垂直切片**证明乐趣为先。

## 平台节奏
PC + 手游先行 → 后端在线化 → 实时 PvP → 主机移植(手柄全手动优先,移植成本可控)。
