# 模块设计规格 — SLG 经济闭环(v1 纸面)

> 域:MetaLayer / Track B。Phase 0~2 逐步落地。状态:⬜ 规划(纸面 PrevizGate)。
> 目标:设计一套"打比赛→产出→养成→变强→打更强比赛"的可持续经济闭环,并预留付费入口。

## 1. 资源体系(术语见 glossary)
| 资源 | 代码标识 | 主要产出 | 主要消耗 | 性质 |
|---|---|---|---|---|
| 资金 | Funds | 赢比赛、商业建筑、联赛奖励 | 球员训练、建筑升级 | 软货币(高频) |
| 训练点 | TrainingPoints | 训练中心产出、日常 | 球员升级/技能 | 养成货币 |
| 转会点 | TransferPoints | 比赛/活动/碎片转化 | 抽卡(Signing) | 抽卡货币 |
| 声望 | Prestige | 联赛/联盟排名 | 社交特权、稀有兑换 | 社交货币 |
| 钻石 | Gems | 付费 + 少量免费 | 加速、稀有抽卡、礼包 | 硬通货(付费) |
| 球员碎片 | Fragments | 重复抽卡、活动 | 合成/突破球员 | 养成 |

## 2. 核心闭环
```
打比赛(Track A)──赢──▶ Funds + TransferPoints + Fragments + Prestige
        ▲                              │
        │                              ▼
   阵容更强 ◀──养成──── 训练球员 / 抽卡(Signing) / 升级俱乐部建筑
        │                              │
        └────── 打更高级别比赛/联赛 PvP ◀┘
```
(图见 `economy-loop.svg`)

## 3. 时间门控与付费入口(对标头部 SLG)
- **加速(Speed-up)**:建筑升级/训练有真实耗时,Gems 可加速 → 头部 SLG 的核心付费点。
- **首充诱导**:$1~3 低价首单含"额外训练队列 + 一名 SR/UR 球员"(对标 Last War)。
- **VIP / 赛季通行证**:Phase 3+。
- **原则**:Phase 0~2 先把闭环跑通(单机、占位数值),付费阀门 Phase 3+ 再开。

## 4. 与 Track A(比赛)的接口
- **输出给比赛**:阵容(11 名 Footballer 的属性)→ 决定比赛中球员能力(见 `footballer-data/spec.md`)。
- **从比赛接收**:比赛结果(胜负/比分/球员表现)→ 换算资源产出。
- 换算示例(占位):胜 +100 Funds +10 TransferPoints;每球员评分→少量 TrainingPoints。

## 5. 俱乐部建筑(资源引擎,v1)
| 建筑 | 作用 |
|---|---|
| 球场 Stadium | 提升比赛奖励上限、容纳/门票 Funds |
| 训练中心 Training | 产出 TrainingPoints、解锁训练位 |
| 青训营 Academy | 周期产出低星球员/碎片 |
| 医疗室 Medical | 降低球员疲劳恢复时间 |
| 商业区 Commercial | 持续产出 Funds(放置收益) |

## 6. 数值原则(防通胀)
- 软货币高频小额,硬通货低频高价。
- 养成曲线随等级指数上升,制造长期消耗(无底洞)。
- 所有数值走 DataTable,便于快速调平衡;上线后服务器权威校验。

## 7. 验收(纸面 PrevizGate)
- [ ] 闭环逻辑自洽:每种资源都有清晰产出与消耗,无死货币。
- [ ] 与比赛接口清晰(阵容→比赛→结果→资源)。
- [ ] 付费入口位置合理且不破坏早期体验。
