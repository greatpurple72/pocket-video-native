# 模块设计规格 — SLG 世界大地图 / GvG(World Map)v1

> 域:MetaLayer / Track B(后期)。状态:⬜ 规划(设计师定稿,出概念实机图)。
> 综合参考:无尽冬日(中央要塞 Sunfire/联盟领地/资源野怪/行军)、Last War(Frontier 村→扩张→中央 Capitol + Shrine 环 / 跨服 Capital Clash)、足球全球化设定。

## 1. 地理与视角
- **写实世界地图**(可辨认大陆/海洋),3/4 俯视,高品质游戏化渲染(非太空看地球、非单一球场)。
- 真实地理基底:不同大洲/国家区域 → 联盟领地着色。

## 2. 地图要素(足球化映射)
| 通用 SLG | 本作足球化 |
|---|---|
| 中央 Capitol/Sunfire | **世界冠军球场**(赛季终极争夺目标) |
| 环绕强据点 Shrine Ring | **地标球场强据点**(温布利/伯纳乌/马拉卡纳式,控制通往中心的路) |
| 玩家城/基地 | **俱乐部球场城**(每个玩家一个,边缘=新手 Frontier 俱乐部,向内越强) |
| 联盟/领地 | **足协/联盟**,用队色占据大洲/国家领地,占城扩张 |
| 资源田 | **训练场 / 青训营 / 转会市场 / 赞助商总部**(产出训练点/转会点/金币) |
| 野怪 NPC | **劲敌俱乐部 / 传奇球星挑战**(攻打得奖励) |
| 行军部队 | **球队大巴 / 球员小队**(沿路行军 + 倒计时) |
| 赛季/跨服战 | **跨服联盟争霸 · Capital Clash → 争夺世界冠军球场** |

## 3. 玩法循环(后期 GvG)
迁入边缘 Frontier 俱乐部 → 采集资源/打 NPC 扩张 → 加入足协占领地 → 集结行军攻打地标球场强据点 → 跨服赛季冲击中央**世界冠军球场**,按控制点积分定胜负。

## 4. UI(实机界面)
- 顶部:玩家头像+战力、资源条(金币/钻石/训练点/转会点/体力)。
- 中央顶:当前争夺目标 + 倒计时(世界冠军球场争夺 02:14:30)。
- 左侧浮钮:邮件/任务/活动/VIP;右侧:联盟/集结/搜索/世界-城市切换/缩放。
- 左下:聊天(世界/联盟频道,显示其他玩家发言);右下:小地图。
- 地图上:大量**其他玩家俱乐部基地**带名字+联盟标签+坐标(体现多人在线);行军虚线+倒计时;领地色块。

## 5. 概念实机图产出
- 底图:fal.ai/FLUX 出写实世界地图(大陆+球场城基地+中央大球场+地标环)。
- UI:`scripts/compose_map_ui.py` 叠加上述实机 UI + 多玩家名字 → `generated/map-ui-world.png`。
