# 实机模拟 PV 制作包 —— SeeDance 2.0(图生视频)

> 目标:用 SeeDance 2.0 把已生成的实机概念图做成一段 **~75–90 秒的"模拟实机录屏 PV"**,提前呈现成品样子,**供领导审核**。
> 路径:**图生视频(i2v)**——每个镜头用下面指定的"参考首帧图"当首帧 + 对应运镜提示词,生成 5–6 秒 clip,再按分镜剪成长片。
> 画风基线:写实向次世代足球(ADR-0005),角色写实+头略大;界面=实机 UI。

---

## 一、SeeDance 2.0 操作要点
1. 选 **图生视频(image-to-video)**,上传"参考首帧"(见分镜表,文件在 `docs/design/art/generated/`)。
2. 比例 **16:9**,清晰度尽量最高;每段时长 **5s**(片头/大地图可 6–10s)。
3. 运镜提示词只描述**镜头运动 + 画面内动作**,别改画风(首帧已定调)。
4. 每段都加这句**稳定词**:`保持写实游戏实机画面,运动流畅自然,无变形、无多余手指、像真实游戏录屏`。
5. 同一主角/球星多镜头时,尽量用同一张首帧或同系列图,保证一致。

## 二、全局风格词(可选加在每条末尾)
`次世代足球游戏实机画面,EA FC / eFootball 级,写实+头部略大风格,夜场灯光,电影级运镜,4K`

## 五、剪辑指引(剪映 / CapCut / 即梦剪辑)
1. **顺序**:按分镜 1→14。开场片头→玩法(比赛/技巧/点球/庆祝)→养成(主城/阵容/抽卡/球星)→SLG(大地图/集结/赛季)→快剪高潮→片尾。
2. **转场**:玩法段用快切/闪白卡鼓点;系统段用轻微滑入/叠化。
3. **字幕**:大号粗体居中或下三分之一,中英双语更显国际化;每镜 1 句,停留 1.5–2s。
4. **音乐**:史诗管弦 + 电子鼓点,前段铺垫、快剪段鼓点最密、片尾收束;约 80s 选一首有渐强的曲子。
5. **节奏**:前 5 镜每镜 5–6s,快剪段每个子镜 0.5–1s,片尾留 5–6s。
6. **画幅/导出**:16:9,1080p 或更高,30fps,MP4。
7. **统一调色**:全片套一个轻微"电影级"LUT,让不同 clip 色调一致。

## 六、一致性技巧
- 全程主队色统一(如翠绿/红),主角球星尽量复用同一张图做多镜头。
- 每段 SeeDance 都带"稳定词",避免画面漂移/变形。
- 先各自生成全部 clip → 统一进剪辑软件 → 套同一 LUT + 同一音乐 → 加字幕/LOGO。
