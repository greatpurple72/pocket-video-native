# 美术(Art Direction)— 设计总览

> 美术基调已定调(PrevizGate 通过,2026-06-19)。归档:ADR-0004、`previz/art-style-previz.md`。

## 已定基准
- **全局画风:卡通 / chibi(方向 C)** — 核心比赛与买量素材统一卡通,无风格割裂。
- **买量小游戏:踢球类爽点玩法** — 点球、任意球、过人挑战、射门 timing(chibi 呈现)。
- **定位**:街机 / 休闲向足球 SLG(非拟真 sim);玩法仍为实时可控 11v11。
- 主色基调:高饱和糖果色系(球场绿为主,辅以亮色队服/UI)。
- 头身比:偏 chibi(约 1:3~1:4,具体在角色 PrevizGate 细化)。

## 产物
- `previz/style-board.svg` — 风格板(三方向对比)
- `previz/art-style-previz.md` — 风格 PrevizGate(已批准)+ AI 绘图提示词

## 原则
- 单人+AI 可量产优先:Fab/Mixamo/商城现成卡通资源,先占位后替换。
- chibi 风格性能开销低,移动端友好,买量素材成本低、病毒力强。
- 后续每个具体美术资产(角色/球场/UI/小游戏)各自走 PrevizGate,均以本卡通基准为准。
