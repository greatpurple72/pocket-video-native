# 美术(Art Direction)— 设计总览

> 美术方向以最新 ADR 为准:**ADR-0005 写实向(实机截图)**,取代 ADR-0004 卡通。

## 已定基准(ADR-0005)
- **方向:写实向次世代足球游戏**,对标 EA Sports FC / eFootball 的**实机游戏截图**观感。
- **球员:成熟硬核,约 5~5.5 头身**,写实球衣/皮肤/面部;支撑真人球星授权形象。
- **概念图=模拟实机截图**(HUD + 转播镜头 + 写实球场),不要示意图。
- 目标付费人群:成年硬核男性球迷。

## AAA 概念图产出
- 工具:**fal.ai / FLUX**(`scripts/gen_fal.py`,密钥走环境变量)。
- 成品:`docs/design/art/generated/`(01 比赛 / 02 球星 / 03 俱乐部 / 04 开包 / 05 点球 / 06 进球)。
- 备选:即梦提示词包 `jimeng-prompt-pack.md`(需改写实提示词)。

## 真人球星授权
- 概念图阶段用**通用球员**(不生成具体真实名人脸)。
- 授权球星形象在 **UE5 阶段**用授权扫描 / MetaHuman 落地。

## 历史
- ADR-0004(卡通 chibi)已废弃:审核不合格(太 Q、无法吸引硬核球迷付费)。
