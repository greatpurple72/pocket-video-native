# ADR-0004 — 美术风格:全局卡通(chibi)

- 状态:**已被取代(Superseded by ADR-0005)** — 卡通方向审核不合格,改为写实向。
- 日期:2026-06-19

## 背景
Phase 0 首个 PrevizGate(美术风格定调)。候选 A 写实 / B 风格化半写实 / C 卡通 chibi。
云端推荐 B(核心)+ C(买量)。用户决定:**全局统一用 C 卡通**,买量小游戏用踢球类玩法。

## 决策
- **全局美术风格 = 卡通 / chibi(方向 C)**,核心比赛与买量素材统一。
- **买量小游戏(HookMinigame)= 踢球类爽点**:点球、任意球、过人、射门 timing。
- 产品定位由"拟真足球 sim"调整为**"街机/休闲向足球 SLG"**;实时可控玩法不变。

## 理由
- 单人+AI 可量产性最高;跨端性能最好;买量力最强(对标 Last War/Kingshot 的 chibi 买量优势)。
- 核心与买量风格统一 → 无"广告≠游戏"的风格落差,转化更顺,资产可复用。
- 足球踢球类小游戏天然适配 chibi 爽点广告。

## 权衡 / 代价
- 放弃"画面对标 eFootball"的拟真代入感。→ 用实时可控的玩法手感与街机爽感补偿;调性更全球大众化。
- 需在卡通框架内做出"足球感"与可读性(球员辨识、战术站位)。→ 后续角色/球场 PrevizGate 专门把控。

## 影响
- 取代风格选型层面的 B 推荐(本 ADR 为最终)。
- 所有后续美术资产以卡通基准制作;`design/art/README.md` 为基准文档。
- `vision/vision.md` 定位口径相应更新为"街机/休闲向足球 SLG"。
