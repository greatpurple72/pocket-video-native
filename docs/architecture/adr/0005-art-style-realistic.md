# ADR-0005 — 美术风格改为写实向(次世代足球实机截图)

- 状态:已采纳(Accepted)
- 日期:2026-06-19
- 取代:**ADR-0004(全局卡通 chibi)** → 本 ADR 取代之

## 背景
卡通/Q 版效果图经审核**不合格**:过于可爱,无法让成年硬核男性球迷产生付费欲,也对不起真人球星授权形象。

## 决策
- 美术方向改为 **写实向次世代足球游戏**,对标 **EA Sports FC / eFootball** 的**实机游戏截图**观感。
- 球员:**写实渲染,头部仅微放大(约 6.5 头身)**,提升辨识度/亲和力,**仍写实、绝非卡通/Q 版**;正常球衣短裤;支撑真人球星授权形象。
  - 注:试过 5 头身风格化(王者/守望风)被否——太卡通;最终=写实+头略大。
- **SLG 大地图按真实地球设定**:真实大陆/国家/城市做基地与联盟领地,跨城/跨洲行军,全球 GvG。
- 所有概念图以"**模拟实机截图**"为准(带 HUD、转播镜头、写实场景),**不要示意图**。
- 买量小游戏同样写实呈现(非 chibi)。

## 理由
- 目标付费人群=成年硬核球迷,需要写实代入感与"对得起授权"的品质。
- 与"亲手踢实时比赛"的体育核心调性一致。

## 代价 / 权衡
- 写实对美术/性能/单人+AI 成本更高(对比卡通)。→ 概念图用 AI(fal.ai/FLUX)产出;实机走 UE5 + 写实资源(MetaHuman 等),分阶段逼近。

## 影响
- `design/art/README.md` 基准更新为写实。
- 概念图产出脚本 `scripts/gen_fal.py` 提示词改为写实实机截图风。
- 真人球星授权形象在 UE5 阶段用授权扫描/MetaHuman 落地(概念图阶段用通用球员,不生成具体真实名人脸)。
