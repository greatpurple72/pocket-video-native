# ROADMAP —— 阶段、里程碑与当前位置

> 用"里程碑 + 验收闸门",不用绝对日历(单人节奏波动大)。
> **当前位置**永远标在下方。每个模块进入制作前先过 **PrevizGate**(效果图/视频审核)。

## ▶ 当前位置:Phase 0 准备中(等待用户批准计划 + 创建 UE 工程仓库)

---

## 双轨并行说明(用户要求:手感与 SLG 大循环同时推进)
- **Track A — 比赛手感(主轴)**:Phase 0→1 死磕实时 11v11 手感。
- **Track B — SLG 大循环(并行)**:与 A 同步搭建俱乐部/球员/经济/联赛的**单机元层**,先用占位数据驱动,等比赛可玩后接入。
- 两轨共享同一套养成经济(见 `design/slg/`)与术语(`vision/glossary.md`)。

---

## Phase 0 — Walking Skeleton(走骨架)
- A:UE5 工程、球场、1 名可控 Footballer、球物理、带球射空门。
- B:元层数据骨架(Footballer 属性表、Club 存档结构、主菜单壳)。
- **闸门**:① PrevizGate 通过 ② 手柄/键鼠能带球射门、手感方向对。

## Phase 1 — 一场能踢的标准比赛(核心垂直切片)★最重要
- A:**标准 11v11**、队友/对手 AI、传/射/抢断、进球、计时比分、SmartAssist 传球、基本规则(界外/进球;越位可后置)。
- B:赛后结算 → 资源产出 → 球员养成 → 阵容影响下一场。
- **闸门**:① PrevizGate 通过 ② "想再来一局"。

## Phase 2 — 元层 v1(俱乐部 + 抽卡 + 养成,单机)
- 俱乐部建筑、Signing 抽卡、球员训练升级、阵容编辑、UMG 主界面、本地存档。
- **闸门**:"打比赛→变强→打更强比赛"闭环成立,养成对比赛可感知。

## Phase 3 — 生涯 + Hybrid-casual 钩子
- 赛季/联赛(对 AI,升降级)、引导漏斗、HookMinigame(点球/任意球/过人)、单机版每日/首充/任务。
- **闸门**:新玩家 30 分钟留得住;小游戏单独也好玩(买量素材潜力)。

## Phase 4 — 平台化与移动端
- Windows 打包、Android 打包 + 触屏 UI/SmartAssist、画质分级、输入抽象统一。
- **闸门**:手机能流畅踢一局,触屏手感可接受。

## Phase 5 — 在线化与 SLG 长线(后端启动)
- 后端账号/存档/经济校验、异步 PvP、Alliance、CrossServer League 雏形、活动配置化。
- **闸门**:两 User 能异步对战影响排名;经济不可本地篡改。

## Phase 6 — 北极星
- 实时 PvP(UE5 replication/回滚)、主机移植、深度商业化(VIP/赛季通行证/转会窗)、反作弊、数据驱动运营。
